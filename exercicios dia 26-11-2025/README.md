# 📚 Banco de Dados - Exercícios do Dia

Este diretório contém três atividades práticas de Banco de Dados, cada uma com seu respectivo script `.SQL` contendo a criação de tabelas, inserção de dados e consultas.

---

## 🧑‍💼 Atividade 01 - Sistema de RH

**Banco de Dados:** `db_rh`  
**Objetivo:** Gerenciar informações dos colaboradores de uma empresa.

### Requisitos:
- Criar a tabela `tb_colaboradores` com 5 atributos relevantes (ex.: nome, cargo, salário, setor, data_admissao)
- Inserir no mínimo 5 registros
- Consultas:
  - SELECT colaboradores com **salário maior que 2000**
  - SELECT colaboradores com **salário menor que 2000**
  - Atualizar um registro usando `UPDATE`
- Salvar todas as queries em um único arquivo `.SQL`
